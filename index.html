Настройки

❤️ Как настроить запись в Apple Health (один раз)
  1. Откройте приложение «Команды» (Shortcuts) на iPhone → «+» — новая команда.
  2. Назовите её точно так же, как в поле «Имя Команды» выше (по умолчанию ПП Здоровье).
  3. Добавьте действие «Разделить текст»: входные данные — «Вход команды», разделитель — Пользовательский = запятая «,».
  4. Добавьте «Записать образец здоровья» → тип Питание › Энергия рациона, значение = Элемент 1 из разделённого текста (ккал).
  5. Ещё три раза «Записать образец здоровья»: Белки = Элемент 2, Жиры общие = Элемент 3, Углеводы = Элемент 4.
  6. Готово. Теперь кнопка «Записать в Здоровье» в приложении будет открывать эту Команду с уже подставленными числами.

Приложение передаёт в Команду строку вида ккал,белки,жиры,углеводы — например 430,32,14,40.
