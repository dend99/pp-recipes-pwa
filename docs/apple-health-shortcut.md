# Запись питания в Apple Health через «Команды» (Shortcuts)

Приложение — это PWA, и напрямую в Apple Health писать не может (веб-API для
HealthKit не существует). Но это умеет системное приложение **«Команды»**
(Shortcuts). Приложение открывает вашу Команду и передаёт ей КБЖУ блюда/дня —
Команда записывает их в «Здоровье». **Apple Developer, Mac и App Store не нужны.**

## Как это работает

Кнопки **«Записать в Здоровье»** (в карточке рецепта и в дневнике) открывают
ссылку вида:

```
shortcuts://run-shortcut?name=ПП%20Здоровье&input=text&text=430,32,14,40
```

То есть в Команду передаётся строка **`ккал,белки,жиры,углеводы`** (например
`430,32,14,40`). Команда разбирает её и делает 4 записи в «Здоровье».

## Настройка Команды (один раз, ~2 минуты)

1. Откройте приложение **«Команды»** → вкладка «Мои команды» → **«+»**.
2. Нажмите на название вверху → **переименуйте** ровно так, как указано в
   приложении в поле **«Имя Команды»** (по умолчанию **`ПП Здоровье`**).
   Имя должно совпадать символ-в-символ.
3. Добавьте действие **«Разделить текст»**:
   - текст → выберите **«Вход команды» (Shortcut Input)**;
   - разделитель → **Пользовательский** → введите запятую `,`.
4. Добавьте действие **«Записать образец здоровья»**:
   - Тип → **Питание → Энергия рациона**;
   - Значение → **«Элементы из разделённого текста» → Элемент 1** (это ккал);
   - Единица → **ккал**.
5. Ещё три раза добавьте **«Записать образец здоровья»**:
   - **Белки** → значение = **Элемент 2** (г);
   - **Жиры общие** → значение = **Элемент 3** (г);
   - **Углеводы** → значение = **Элемент 4** (г).
6. (Необязательно) добавьте в конце **«Показать уведомление»** = `Записано в Здоровье`.
7. Сохраните. При первом запуске iOS спросит разрешение на доступ к «Здоровью» —
   разрешите запись.

## Проверка

В приложении откройте любой рецепт → **«❤️ Записать в Здоровье»**. Откроются
«Команды», выполнится запись, и в приложении **Здоровье → Обзор → Питание**
появятся калории и Б/Ж/У.

## Заметки

- Если переименовали Команду — впишите новое имя в приложении: **Дневник →
  Настройки → «Имя Команды»**.
- Кнопка в **дневнике** пишет сумму за выбранный день; кнопка в **карточке
  рецепта** — одну порцию блюда.
- Всё работает локально и бесплатно; данные о питании хранятся в вашем «Здоровье».
