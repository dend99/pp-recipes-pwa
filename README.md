# 🥗 ПП Рецепты — PWA для быстрых блюд и похудения

Прогрессивное веб-приложение (PWA) с рецептами правильного питания: быстрые,
вкусные и оптимальные по КБЖУ блюда для похудения. Работает **полностью
оффлайн** на iPhone и Android — устанавливается на домашний экран, без App Store.

## Возможности

- 🧊 **Подбор по холодильнику.** Отметьте продукты, которые есть под рукой, и
  выберите приём пищи (завтрак/обед/ужин/перекус) — приложение сразу покажет
  подходящие рецепты, отсортированные по проценту совпадения ингредиентов.
- 📖 **База из 84 рецептов** (Банк №1, рацион ~2100 ккал/день: по 21 блюду на
  завтрак, обед, перекус и ужин) с фото/заглушкой, тегами и временем готовки.
- 🔎 **Поиск по ингредиентам** и названию рецепта.
- 🧮 **КБЖУ у каждого рецепта** (калории / белки / жиры / углеводы) — на порцию
  и на 100 г. У блюд из банка сохранены авторские выверенные значения; у ваших
  рецептов КБЖУ считается автоматически по базе из **114 продуктов**.
- 🧂 **Добавки указаны явно.** Разрыхлитель, сахарозаменитель, ванилин, специи,
  корица и т.п. включены в состав рецептов — они попадают и в рецепт, и в список
  покупок (калорийность у них ~0, поэтому КБЖУ рациона не искажается).
- ➕ **Быстрое добавление рецептов**: выбираете ингредиенты с граммовкой, КБЖУ
  пересчитывается на лету; можно приложить фото блюда с камеры.
- 📥 **Импорт и экспорт** рецептов одним JSON-файлом (перенос между устройствами,
  резервная копия) — с валидацией и защитой от дублей.
- 🛒 **Список покупок** — собирается из ингредиентов рецептов (включая добавки),
  группируется по категориям, синхронизируется с чекбоксами.

## Как это работает

Чисто клиентское приложение: HTML + CSS + ванильный JavaScript. Никакого
бэкенда — все рецепты и списки хранятся локально в `localStorage` браузера.
Service Worker (`sw.js`) кэширует оболочку приложения, поэтому оно открывается
и работает без интернета.

## Установка на iPhone (локально)

1. Разместите файлы на любом HTTPS-хостинге (GitHub Pages, Netlify, свой сервер)
   — PWA требует HTTPS. Для локальной проверки: `python3 -m http.server 8099`.
2. Откройте адрес в **Safari** на iPhone.
3. Нажмите «Поделиться» → **«На экран Домой»**.
4. Приложение появится иконкой и будет работать оффлайн как нативное.

> На Android — то же самое через Chrome: меню → «Установить приложение».

## Структура

```
index.html               # оболочка приложения (4 вкладки)
css/styles.css           # стили (мобайл-фёрст, тёмная тема, safe-area iOS)
js/data.js               # база КБЖУ ингредиентов (114 продуктов)
js/bank.js               # Банк рецептов №1 — 84 рецепта (компактный формат)
js/app.js                # вся логика (подбор, расчёт, хранение, импорт/экспорт)
manifest.webmanifest     # манифест PWA
sw.js                    # service worker (оффлайн-кэш)
icons/                   # иконки приложения
gen_icons.py             # генератор иконок (pure Python, без зависимостей)
```

## Расчёт КБЖУ

Значения БЖУ и калорийности продуктов хранятся в `js/data.js` (на 100 г).
Для **пользовательских** рецептов КБЖУ суммируется по ингредиентам с учётом
граммовки и делится на число порций. Для рецептов **из банка** (`js/bank.js`)
показываются авторские значения на порцию (поле `nutrition`) — они выверены под
рацион ~2100 ккал/день.

## Как добавить новый банк рецептов

1. Оформите рецепты в формате `RAW_BANK` внутри `js/bank.js` (или отдельным
   файлом по образцу).
2. Недостающие продукты добавьте в массив `INGREDIENTS` в `js/data.js`.
3. Поднимите `SEED_VERSION` в `js/app.js` — при следующем запуске новые рецепты
   до-загрузятся в уже установленные копии, не трогая пользовательские.
4. Обновите версию кэша `CACHE` в `sw.js`, чтобы обновление подхватилось оффлайн.
